Token-Vorhersage

Wie LLMs das nächste Wort wählen

Sprachmodelle sagen das nächste Wort vorher, basierend auf Wahrscheinlichkeiten. Diese Demo zeigt, wie das funktioniert.

Probiere es aus

Wähle einen Satzanfang und sieh, welche Wörter das Modell als nächstes vorschlagen würde.

Key-pointWas du siehst

Das Modell berechnet für jedes mögliche Wort eine Wahrscheinlichkeit. Die Auswahl basiert auf Mustern in den Trainingsdaten, ohne eingebaute Prüfung der faktischen Korrektheit.

Temperature: Wie viel Zufall?

Der Parameter “Temperature” steuert, wie das Modell aus den Wahrscheinlichkeiten wählt.

viewof temperature = Inputs.range([0.1, 2.0], {
  value: 1.0,
  step: 0.1,
  label: "Temperature",
  width: 400
})
scaledProbs = {
  const t = temperature;
  const logits = currentProbs.map(p => Math.log(p.prob));
  const scaled = logits.map(l => Math.exp(l / t));
  const sum = scaled.reduce((a, b) => a + b, 0);
  return currentProbs.map((p, i) => ({
    token: p.token,
    prob: scaled[i] / sum,
    original: p.prob
  }));
}

temperatureDescription = {
  if (temperature < 0.5) return {
    emoji: "🎯",
    text: "Sehr deterministisch",
    detail: "Fast immer das wahrscheinlichste Wort. Vorhersehbar, aber manchmal langweilig."
  };
  if (temperature < 1.0) return {
    emoji: "⚖️",
    text: "Ausgeglichen",
    detail: "Gute Mischung aus häufigen und weniger häufigen Wörtern."
  };
  if (temperature < 1.5) return {
    emoji: "🎲",
    text: "Kreativ",
    detail: "Mehr Variation und überraschendere Ausgaben. Kann interessanter sein."
  };
  return {
    emoji: "🌀",
    text: "Chaotisch",
    detail: "Fast zufällige Auswahl. Oft unsinnige oder zusammenhanglose Texte."
  };
}

ReflectReflexion
  • Bei niedriger Temperature (0.1-0.5): Das Modell wählt fast immer das wahrscheinlichste Wort. Gut für Fakten, schlecht für kreative Texte.
  • Bei hoher Temperature (1.5+): Das Modell wählt öfter unwahrscheinliche Wörter. Kann kreativ sein, aber oft unsinnig.
  • Standardwert 0.7-1.0: Balanciert zwischen Kohärenz und Variation.

Was das für die Lehre bedeutet

Key-pointKernaussagen

  1. Keine eingebaute Faktenprüfung: LLMs generieren Text basierend auf Mustern, ohne externe Verifikation.

  2. Kontext ist entscheidend: Die Wahrscheinlichkeiten ändern sich komplett, je nachdem was vorher steht.

  3. Halluzinationen erklären: Wenn ein falsches Wort hohe Wahrscheinlichkeit hat (weil es in den Trainingsdaten oft vorkam), wird es gewählt, auch wenn es faktisch falsch ist.

  4. Temperature für Aufgaben anpassen:

    • Zusammenfassungen: Niedrig (0.3-0.5)
    • Kreatives Schreiben: Höher (0.8-1.2)
    • Brainstorming: Noch höher (1.0-1.5)
